1. Overview

This automated testing tool validates the Enterprise EPP Aggressive Mode feature. It runs a series of positive and negative test cases to verify that:

  • Malicious processes are terminated (Aggressive Mode working correctly)
  • Safe processes are NOT terminated (No false positives)

The tool generates detailed HTML, JSON, and CSV reports showing process tree visualization, kill latency metrics, and pass/fail status for each test.

2. What is Aggressive Mode?

Aggressive Mode is a Enterprise EPP feature that:

  1. Detects malicious activity in child processes
  2. Terminates both the child AND parent process to stop the threat at the source
  3. Prevents malware from respawning by killing the entire process tree
Why Test This? To verify EPP correctly identifies threats, ensure legitimate applications aren't killed (false positives), and measure response time (kill latency).

4. Installation Steps

Copy the Setup Script

Copy setup_aggressive_mode_tool_v7.py to your target machine (e.g., Desktop)

Open Command Prompt as Administrator

Press Win + R → Type cmd → Press Ctrl+Shift+Enter

Navigate to Script Location

cd C:\Users\<username>\Desktop

Install Required Package

pip install psutil

Run the Setup Script

python setup_aggressive_mode_tool_v7.py

This creates the AggressiveMode-Automation folder with all necessary files.

Navigate to Tool Directory

cd AggressiveMode-Automation

Files Created

AggressiveMode-Automation/ ├── monitor.py # Main test runner ├── test_payload.py # Positive test payloads (with EICAR) ├── safe_payload.py # Negative test payloads (safe) ├── launcher.py # Simple wrapper script ├── requirements.txt # Dependencies ├── run.bat # Quick run batch file └── reports/ # Generated reports folder

5. Running Tests

Common Commands

Command Description
python monitor.py Run all 15 tests (10 positive + 5 negative)
python monitor.py --timeout 60 Set 60-second timeout per test
python monitor.py -p powershell cmd Run only specified positive tests
python monitor.py -n safe_notepad Run only specified negative tests
python monitor.py -p powershell -n safe_notepad Run mix of positive and negative tests
Quick Start To run all tests with default settings, simply run: python monitor.py

6. Understanding Results

How to Interpret Results

POSITIVE Tests (Malicious)

PASS = Process was KILLED by EPP

FAIL = Process was NOT killed (EPP missed threat)

Uses EICAR test pattern to trigger EPP detection

NEGATIVE Tests (Safe)

PASS = Process was NOT killed

FAIL = Process was KILLED (false positive)

Uses safe commands only, no EICAR pattern

Ideal Outcome All POSITIVE tests = PASS (malicious processes killed)
All NEGATIVE tests = PASS (safe processes not killed)
Concerning Results POSITIVE test FAIL = EPP missed a threat (needs investigation)
NEGATIVE test FAIL = EPP has false positives (too aggressive)

7. Test Cases Explained

POSITIVE Tests (10 Total) - Should Be KILLED

These tests create the EICAR test file (industry-standard antivirus test pattern) and should trigger EPP.

# Test Name Process Risk What It Does
1 PowerShell + EICAR powershell.exe HIGH Creates EICAR using Set-Content with ExecutionPolicy Bypass
2 CMD + EICAR cmd.exe MEDIUM Uses echo to write EICAR to file
3 WScript + EICAR wscript.exe HIGH VBScript creates EICAR via FileSystemObject
4 CScript + EICAR cscript.exe HIGH Console VBScript creates EICAR
5 MSHTA + EICAR mshta.exe HIGH HTML Application with embedded VBScript
6 Certutil + EICAR cmd.exe MEDIUM Abuses certutil -decode (LOLBin technique)
7 BITSAdmin + EICAR cmd.exe MEDIUM Uses BITSAdmin alongside EICAR creation
8 Rundll32 + EICAR cmd.exe HIGH Simulates rundll32 abuse pattern
9 Regsvr32 + EICAR cmd.exe HIGH Simulates regsvr32 AppLocker bypass
10 WMIC + EICAR cmd.exe MEDIUM Uses WMIC with EICAR creation

NEGATIVE Tests (5 Total) - Should NOT Be Killed

These tests run completely safe commands with NO EICAR pattern. EPP should NOT kill these.

# Test Name Process What It Does
1 Safe PowerShell powershell.exe Get-Date, Write-Host - read-only commands only
2 Safe CMD cmd.exe echo, dir - no file writes
3 Notepad notepad.exe Opens Windows Notepad (GUI app)
4 MS Paint mspaint.exe Opens MS Paint (GUI app)
5 Safe Ping cmd.exe Pings localhost (127.0.0.1) only

8. Troubleshooting

Issue Solution
"Module psutil not found" Run: pip install psutil
Script hangs on GUI tests Press Ctrl+C and retry. V7 has improved GUI handling.
Tests timeout without results Increase timeout: python monitor.py --timeout 60
Permission denied errors Run Command Prompt as Administrator
All negative tests fail EPP may have false positives. Review EPP detection rules.
Process shows KILLED but app still running May be a UWP app issue. V7 uses trackable Win32 apps.
